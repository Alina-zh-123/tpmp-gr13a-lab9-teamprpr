# Project Name: Aurora Mobile Banking

# Description

Мобильное приложение банка, разработанное на фреймворке SwiftUI с поддержкой CoreData для работы с базой данных. Программа предоставляет защищенную авторизацию, после которой пользователь получает доступ к главному меню для управления финансами. Основной функционал включает просмотр активных и заблокированных счетов различных типов (текущие, сберегательные, кредитные, карт-счета), отображение актуального курса валют, а также интерактивную карту MapKit со встроенным алгоритмом автоматического поиска ближайшего отделения. Приложение полностью локализовано на три языка (английский, итальянский, русский) и сохраняет состояние авторизации между сессиями.

# Usage

1. **Авторизация:** При запуске приложения введите любые непустые значения в поля *Логин* и *Пароль*, после чего нажмите кнопку *"Войти"*. Состояние сессии сохранится в `UserDefaults` с помощью свойства `@AppStorage`.
<img width="332" height="659" alt="Снимок экрана 2026-05-18 в 7 53 10 PM" src="https://github.com/user-attachments/assets/a939e7de-67b6-4a0b-a371-ba71a6fb136c" />

2. **Главное меню:** Из центрального интерфейса доступны три основных действия:
    * **Мои счета:** переход на экран со списком карт-счетов и депозитов, отфильтрованных по статусу (закрытые счета не отображаются).
    * **Филиалы отделений:** открытие карты со всеми доступными филиалами и автоматическим поиском ближайшей точки по отношению к геолокации клиента.
    * **Курсы валют:** таблица актуальных курсов покупки/продажи популярных валют (USD, EUR, RUB, CNY).

3. **Локализация:** Для проверки мультиязычности измените язык системы в настройках симулятора (`iOS Settings` -> `General` -> `Language & Region`) на английский или итальянский. Интерфейс приложения и предзагруженные данные из CoreData адаптируются автоматически.
