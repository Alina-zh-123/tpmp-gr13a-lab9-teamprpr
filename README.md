## Описание

Мобильное приложение банка, разработанное на фреймворке SwiftUI с поддержкой CoreData для работы с базой данных. Программа предоставляет защищенную авторизацию, после которой пользователь получает доступ к главному меню для управления финансами. Основной функционал включает просмотр активных и заблокированных счетов различных типов (текущие, сберегательные, кредитные, карт-счета), отображение актуального курса валют, а также интерактивную карту MapKit со встроенным алгоритмом автоматического поиска ближайшего отделения. Приложение локализовано на три языка (английский, итальянский, русский) и сохраняет состояние авторизации между сессиями.

## Установка

1. **Подготовка окружения:**
   * ОС macOS 
   * Среда разработки Xcode

2. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/Alina-zh-123/tpmp-gr13a-lab9-teamprpr
   cd tpmp-gr13a-lab9-teamprpr
   ```

3. **Запуск проекта:** Откройте файл `lab9/lab9.xcodeproj` в Xcode, выберите симулятор устройства и запустите проект с помощью сочетания клавиш `Cmd + R`.

## Использование

1. **Авторизация:** При запуске приложения введите любые непустые значения в поля *Логин* и *Пароль*, после чего нажмите кнопку *"Войти"*. Состояние сессии сохранится в `UserDefaults` с помощью свойства `@AppStorage`.

2. **Главное меню:** Из центрального интерфейса доступны три основных действия:
   * **Мои счета:** переход на экран со списком карт-счетов и депозитов.
   * **Филиалы отделений:** открытие карты со всеми доступными филиалами и автоматическим поиском ближайшей точки по отношению к геолокации клиента.
   * **Курсы валют:** таблица актуальных курсов покупки/продажи популярных валют (USD, EUR, RUB, CNY).

3. **Локализация:** Для проверки мультиязычности измените язык системы в настройках симулятора (`iOS Settings` -> `General` -> `Language & Region`) на английский или итальянский. Интерфейс приложения и предзагруженные данные из CoreData адаптируются автоматически.

## Тестирование

Проект полностью покрыт Unit- и UI-тестами для проверки корректности работы бизнес-логики и пользовательского интерфейса. Статистика покрытия кода тестами рассчитывается и проверяется автоматически в рамках настроенного CI/CD пайплайна при каждом обновлении кодовой базы.
