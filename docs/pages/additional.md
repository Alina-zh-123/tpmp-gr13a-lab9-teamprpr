# Дополнительная спецификация

## Системные ограничения

*   **Архитектурный стек:** Приложение разработано с использованием декларативного фреймворка `SwiftUI` для слоя представления и управления локальными данными.
*   **Целевая платформа:** 
    *   Язык разработки: Swift 5.x
    *   Минимальная версия ОС: iOS 15.0+ (для поддержки используемых перегрузок `MapKit` и системных шрифтов).

## Требования к безопасности

*   **Данные статичны и хранятся локально в CoreData.**
*   **Защита учетных данных:** 
    *   Ввод пароля скрывается с помощью компонента `SecureField`.
*  **Отсутствие сетевых запросов** — приложение не передаёт данные пользователя на внешние серверы.

## Надежность и отказоустойчивость

*   **Потокобезопасность CoreData.** 
*   **Безопасный сбой:** 
    *   Блок обработки ошибок при инициализации контейнера CoreData в `PersistenceController` содержит `fatalError()`. 
    *   Отсутствие интернет-соединения отображается на индикаторе `ProgressView`. 
*   **Предотвращение дублирования данных.**

## Удобство использования

* **Интуитивная навигация** — главное меню содержит три ключевые функции.

* **Единый стиль интерфейса** — SwiftUI, единая цветовая схема, адаптация под iOS HIG.

* **Элементы управления** — кнопки и поля ввода адаптированы под мобильные устройства.

* **Минимальное количество действий** — доступ к основным функциям в 1–2 клика.

## Локализация 
*   Приложение поддерживает три языковые локали: **Русский (RU)**, **Английский (EN)** и **Итальянский (IT)**.
*   Локализация интерфейса реализована через системный механизм: файлы `Localizable.strings`.

## Поддержка и расширяемость

* **Модульная структура** — разделение на Model/View /Controller.

* **Лёгкое добавление новых экранов** — навигация через currentScreen.

* **Возможность расширения базы данных** — модель CoreData может быть дополнена новыми сущностями.

* **Поддержка новых языков** — .lproj каталоги.
